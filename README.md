# Online Auction System

## About
An Online Auction System developed as a B.Sc. academic project. The application allows users to browse auction items and participate in bidding.

## Technologies Used
- PHP
- MySQL
- HTML
- CSS
- JavaScript (if used)

## Features
- User registration and login
- Browse auction items
- Auction bidding
- User and auction management

## Requirements
- PHP
- MySQL
- XAMPP or another local PHP server

## How to Run
1. Download or clone this repository.
2. Place the project folder inside the XAMPP `htdocs` directory.
3. Start Apache and MySQL from XAMPP Control Panel.
4. Create/import the project database in phpMyAdmin.
5. Configure the database connection in the project.
6. Open the project in your browser using localhost.
